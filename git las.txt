What happens if you click Download on GitHub?
There are two scenarios:
Scenario A: Download from the repo ZIP ("Code" → "Download ZIP")
❌ This is not recommended.
GitHub downloads only the repository contents, and LFS files may be represented by small pointer files instead of the actual 957 MB ZIP.
Scenario B: Clone with Git LFS
✅ This is the correct way.
